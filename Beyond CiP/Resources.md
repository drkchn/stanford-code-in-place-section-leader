# Resources referenced in the presentation will be linked here

Stay tuned!

1. Data Science: Pandas is the go-to library — Check out Python Data Science Handbook by Jake VanderPlas for all things big data

2. Python programming: CS50 Python from Harvard is a natural next step because it teaches you more programming concepts like file I/O and object-orientated programming

3. Machine Learning: Andrew Ng's Machine Learning Specialization on Coursera is a beginner-friendly approach to understanding ML. Note that you will need math for the course.

4. General programming: CS50 from Harvard dives deeper into computer science and teaches you a wide range of topics, such as C language, basic algorithms, data structures, web development, and more

5. Honorable mentions: Codewars and CodingBat offer programming puzzles where you solve questions using any language. I use these websites myself whenever I need to learn a new language

6. Setting up your IDE: I recommend using VSCode as your IDE, as it is compatible with many languages. Here are some links to help get you started. You can also search on YouTube tutorial videos on how to use VSCode too.
    - [Setting up VSCode](https://code.visualstudio.com/docs/setup/setup-overview)
    - [Quick Start Guide for Python](https://code.visualstudio.com/docs/python/python-quick-start)
